Realizacija:

Kopijuoti

class LibraryCatalog:
    __instance = None

    def __new__(cls):
        if cls.__instance is None:
            cls.__instance = super(LibraryCatalog, cls).__new__(cls)
            cls.__instance.books = []
        return cls.__instance
Paaiškinimas: Užtikrina, kad visos programos metu būtų naudojama tik viena katalogo kopija.

Knygų skolinimas, grąžinimas, rezervavimas ir baudų skaičiavimas
Reikalavimas: Nariai gali skolintis, grąžinti ir rezervuoti knygas; apskaičiuojamos baudos už vėlavimą.

Realizacija:

Kopijuoti

def borrow_book(self, member: Member, book: Book):
    if book.is_available():
        book.mark_borrowed(member)
        member.borrowed_books.append(book)

Redaguoti
def return_book(self, member: Member, book: Book):
    overdue_days = book.mark_returned()
    if overdue_days > 0:
        member.fines += overdue_days * 0.5
Paaiškinimas:

Knygos skolinamos 14 dienų.

Jei grąžinama pavėluotai, taikoma 0.5 USD už dieną bauda.

Rezervacijos galimos, jei knyga jau paskolinta.
